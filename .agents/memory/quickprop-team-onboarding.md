---
name: QuickProp Team Onboarding
description: Required activation and sign-in behavior for newly added QuickProp team members.
---

New team members become active when created or assigned. Do not send password setup links. For desktop sign-in, verify the added email with a one-time code before allowing password creation. In the mobile app, use SMS OTP sent to the provided mobile number.

**Why:** the user specified that team members should be active immediately and should not need a setup link.

**How to apply:** Keep account creation, branch assignment, desktop password setup, and mobile OTP behavior consistent across QuickProp Admin and Office.
