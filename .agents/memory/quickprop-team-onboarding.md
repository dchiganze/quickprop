---
name: QuickProp Team Onboarding
description: Required activation and sign-in behavior for newly added QuickProp team members.
---

New team members become active when created or assigned. Do not send password setup links. Agents who need a desktop password should be able to request an eight-digit email code and verify it before setting a password, without admin involvement. In the mobile app, use SMS OTP sent to the provided mobile number.

**Why:** the user specified immediate activation and self-service email-code password setup without a setup link or admin intervention.

**How to apply:** Keep account creation, branch assignment, desktop password setup, and mobile OTP behavior consistent across QuickProp Admin and Office.
