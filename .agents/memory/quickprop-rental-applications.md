---
name: QuickProp Rental Applications
description: User-specified constraints for tenant references, agency contacts, and rental application access.
---

Rental references must keep exactly four questions: tenancy period; whether rent was paid on time (always, sometimes, never); whether the property was kept presentable (always, sometimes, never); and whether the referee would lease to the tenant again. Keep the official-document/criminal-offence disclaimer with the reference request and form.

Agency referee options must come only from the EAC approved-agents directory, and selectable email addresses or phone numbers must be published there. Tenant rental history belongs to the existing public buyer account profile. Rental applications are private to agents authorized for the associated listing.

**Why:** The user specified the four-question reference and EAC-contact restrictions, and applicant details are sensitive.

**How to apply:** Preserve these rules when changing rental-profile forms, reference email/link flows, the EAC directory, or application access in QuickProp Office and QuickProp Agent.
