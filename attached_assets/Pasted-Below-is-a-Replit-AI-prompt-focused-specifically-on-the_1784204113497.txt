Replit AI Prompt — QuickList Website (Shared Backend Architecture)
Project Overview
Build the public-facing website for QuickList, a Zimbabwean property marketplace and property transaction platform.
The website must share the exact same backend, database, APIs, authentication system, and real-time data layer as:
•	QuickList Agent Mobile App
•	QuickList CRM/Admin Dashboard
The website is not a standalone classifieds website. It is the public discovery layer of a complete property operating system.
The core objective:
Become the most complete and trusted database of active property mandates in Zimbabwe by making property discovery simple while enabling estate agents to manage, distribute and transact efficiently.
