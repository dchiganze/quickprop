Product Overview

Build the public-facing website for QuickList, a Zimbabwean property marketplace.

QuickList consists of three connected products:

Public Website
Buyers and tenants search properties.
Users discover verified property mandates.
Users submit enquiries.
Agent Mobile App
Estate agents capture and manage mandates.
Agents distribute their inventory.
Agents manage leads.
CRM/Admin Dashboard
QuickList manages agents, agencies, listings and marketplace operations.

All three products must run from:

One backend
One database
One API layer
One authentication system

The website must never have separate listing data from the app or CRM.

Any change made in one system must immediately sync across all platforms.

Core MVP Objective

Create the most efficient property discovery platform in Zimbabwe.

The MVP must solve:

Agent Problems
Slow property uploads
Poor internal inventory management
Difficulty finding their own stock
Fragmented WhatsApp/PDF/spreadsheet systems
Difficulty distributing listings consistently
Difficulty managing buyer enquiries
Buyer Problems
Cannot easily find all available properties
Duplicate listings across agents
Poor search experience
Slow response from agents
Lack of trust in listings

Final Product Vision

QuickList is not just another property listing website.

It is a shared property inventory system where:

Agents manage their entire stock
Buyers discover available properties
Agencies organise their business
The market gradually moves from fragmented mandates to transparent inventory

The MVP must first win by being:

The fastest way for agents to manage and distribute property mandates, and the easiest place for buyers to find property.
