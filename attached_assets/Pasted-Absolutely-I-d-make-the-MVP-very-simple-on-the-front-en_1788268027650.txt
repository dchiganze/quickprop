# QuickProp MVP Feature: Rental Profile & Verified Rental History

## Objective

Build a new **"Rental Profile"** tab inside the existing QuickProp prospective buyer/renter profile.

The purpose of this feature is to allow prospective renters to build a simple, credible **rental history** by requesting references from previous landlords or managing estate agencies.

The MVP must be simple, fast and mobile-friendly. Do not build a complicated tenant scoring, credit scoring or background-check system.

The core concept is:

**Tenant adds previous tenancy → QuickProp contacts the actual previous landlord/agent → landlord/agent verifies the tenancy → landlord/agent answers 3 questions → verified reference becomes part of tenant's Rental Profile.**

# 21. Fraud Prevention

Build basic protections into the MVP.

Important:

### Tenant cannot submit their own reference.

The reference answers must only come from the referee flow.

### One verified reference per tenancy.

Prevent duplicate references for the same tenancy.

### Secure reference links.

Use unique, random, expiring tokens.

### Agency references.

Prefer authenticated agency accounts over manually entered email addresses.

### Audit trail.

Record:

* Who submitted
* When
* Account/user ID
* Reference request ID
* Verification timestamp
* Changes/status changes

### Flag suspicious patterns.

Create basic admin flags for things such as:

* Same referee verifying many unrelated tenants
* Multiple tenants using the same private landlord contact details
* Multiple accounts associated with suspicious repeated information
* Repeated references from the same device/IP where technically appropriate
* Rapid creation of many rental histories

Do not automatically ban users based solely on these flags. Flag them for review.
